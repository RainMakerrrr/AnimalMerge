HOW TO USE:
-----------
Simply import the package into your project. 
There are prefabs setup for each intended object, they will already have the correct materials and textures assigned to be ready for use. 

The current texture sizes consist of 512x512's and 1024x1024's.
For optimization reasons; depending on your target device you may want to down size the textures. This is being left to your own discretion.

If for any reason you do not wish to have pirate skulls and bones displayed (For example, on the Town Hall building), you can simply turn them off. 
These are actually seperate objects and can be removed from the objects prefab. 

All of the assets in this project are static assets. They do not include any animations.
However there is a script included called 'RotatorZ' which is assigned onto the windmill assets to make the windmill fan rotate around the z axis.
To use the script, simply drag and drop it onto an object. The script has a field named 'Angular Speed' this controls how fast the object will rotate.
A lower value will make it rotate slower, and a higher value will make it rotate faster.
