# AnimalMerge — Knowledge Base
> Загружается автоматически при старте каждой сессии. Обновляй после значимой работы.

## Проект
Turn-based mobile battler с механикой merge. Unity 2022.3.62f3 · C# · Zenject · UniTask · DOTween · TextMeshPro.
Платформы: Android & iOS. Основная ветка разработки: `iteration_2/Alexandr/Develop`.

## Архитектура
- **Clean Architecture**: Presentation → Application → Domain → Infrastructure
- **DI**: Zenject — никаких Singleton
- **Async**: UniTask везде — никаких Coroutines в новом коде
- **Паттерны**: State (BattleStateMachine), Command (Merge undo), Factory, Facade (AnimalFacade), Observer (SignalBus), Strategy (ITutorialStep, IMergeHintTargetResolver, IBattleReadinessRule)
- **Детали**: `AgentsDocs/ProjectArchitecture.md`

### Синхронизация баланса с концепт-доком 3.0 — спека 06 (не закоммичено)
- **Балансные числа правлены через `SerializedObject`**, а не текстом в `.asset` — иначе память редактора и диск расходятся. Ёж `_tilesPerMove` 3→1 (медленный танк-контратакер), лиса `_ownerDodgeChance` 50→80 / `_inheritedDodgeChance` 30→50 (+ константы-дефолты в `FoxStats.cs` подняты синхронно), курица `_health` 100→25 (стая из 4 = те же 100 HP) и `_tilesPerMove` 2→3, птеродактиль `_health` 200→350 и `_tilesPerMove` 3→5.
- ⚠️ **Курица ОСТАЁТСЯ `_unitSize: 1x1`.** 2х2 — это футпринт **операции спавна**, а не размер юнита: каждая курица независима (свои HP, свой ход, своя смерть, свой `ChickenAttack`). Поднять `_unitSize` до 2х2 значило бы превратить стаю в один большой юнит и обесценить мердж-скилл клонирования. Знание о стае живёт в новом `Assets/Code/Animals/ChickenFlock.cs` (`Footprint` 2x2, `Count` 4).
- **`GridManager.TryFindFreePlacement(size, direction, out anchor)` — единственный алгоритм поиска места**, `HasCellFor` и `PlaceOnGrid` оба делегируют сюда. `AdjustPositionToFitBounds` вызывается **до** `CanPlaceUnit`, наружу отдаётся скорректированный anchor. Попутно починен латентный boundary-баг: `PlaceOnGrid` раньше кормил `GetCell` нескорректированной позицией (проверял одну клетку, занимал другую) — не проявлялся только потому, что никто не запрашивал размещение у самой границы.
- **Спавн стаи атомарен**: `IAnimalFactory.SpawnAdditionalChickens(mainChicken)` → `CreateChickenFlock(IReadOnlyList<IGridCell>)`, а `AnimalSpawner.Spawn` уходит на flock-ветку **до** инстанцирования. Нет блока 2х2 → не создаётся ни одной курицы (раньше главная курица оставалась одна).
- ⚠️ **Откат стаи чистит занятость через `created.Movement.ClearNodes()`, а НЕ через `created.Occupancy`.** `AnimalFacade._occupancy` присваивается в `Start()`, который на момент синхронного `InstantiatePrefabForComponent` внутри фабрики ещё не отработал → `Occupancy` был бы `null` ровно тогда, когда нужен откату. `AnimalMovement._unitOccupancy` присваивается в `Awake()`. **Общее правило: внутри фабрики сразу после инстанцирования доступны только `Awake`-инициализированные поля.**
- **Визуал ×0.75 при мердже курицы** — `MergeAnimationConfig._cloneScaleMultiplier` применяется и к клону, и к оригиналу. `MergeScaleAnimator.GrowBy`/`UndoGrowBy` → `ScaleBy`/`UndoScaleBy` + новый `Resync(Vector3)` (закрыт SUGGESTION прошлой фичи про дрейф `_logicalScale`).
- ⚠️ **Два порядковых инварианта.** (1) `_targetAnimal.ScaleAnimator?.Resync(...)` обязан быть **последним** выражением `MergeCommand.RestoreVisualState`, после `MergeView.UndoVisuals(...)`: внутри `UndoVisuals` отрабатывает `ElephantMergeAttribute.Undo()`, который делит `_logicalScale`, и ранний ресинк оставил бы слона на `preMergeScale / 1.5`. (2) Клона надо ужимать **до** `MergeAppearAnimation.Begin` — `Begin` сразу зовёт `CollapseScaleAndAttachGlow`, который перезатирает `localScale`; `ScaleBy(multiplier, 0f, null)` снапит масштаб и одновременно пишет `_logicalScale`.
- **Шанс контратаки вынесен в данные** по образцу `FoxStats`: новый `Code/Data/Animals/HedgehogStats.cs` (100 владелец / 50 унаследованный), ассет сконвертирован in-place (GUID ассета не менялся). `CounterAttack` стал value-agnostic (`int successChance` вместо `bool isOwner`), `HedgehogFacade` читает `AnimalDatabase`, `HedgehogMergeSkill` хранит `_inheritedChance`.
- **`AnimalFactory` почищена от мёртвого DI**: удалены `SetMergeGrid` (из интерфейса и реализации), поля `_mergeGrid`/`_gridManager`, ctor-параметр `[Inject(Id = GridIdentifier.MergeGrid)] IGridManager`. Правок инсталлера не потребовалось — `Container.Bind<IAnimalFactory>().To<AnimalFactory>().AsSingle()` резолвит ctor-аргументы через контейнер. Закрыт старый `//todo Temp, delete later`.
- **Осознанно не сделано**: §2.8 (иглы ежа) — блокер арт; §3 (прогрессия разблокировки животных) — блокер геймдизайн; `AllySpawnService.SpawnAndRegister` шлёт `AllySpawnedSignal` только с `Unit = spawned[0]`, хотя регистрирует все 4 курицы.

### Выбор животного и карточка статов — `Code/Animals/Selection/` · `Code/Animals/UI/` (не закоммичено)
- **`IAnimalSelectionService` / `AnimalSelectionService` — единственный источник истины о выбранном животном.** Владеет `IMoveRangeHighlighter` (переехал из `AnimalMover`), отдаёт `event Action<AnimalFacade> SelectionChanged` (`null` = сброшено). `IInitializable, ITickable, IDisposable`, биндинг `BindInterfacesAndSelfTo<AnimalSelectionService>().AsSingle()` в `CurrentGameInstaller`.
- ⚠️ **`Tick()` обязателен: `NotifyRemoved()` зовут не все пути уничтожения** — `EnemySpawnService:170`, `AnimalFactory:190`, `ChickenFacade:90/98` уничтожают объект напрямую. Сервис ловит **fake-null** `_selected` в тике, помимо подписки на `AnimalFacade.OnRemoved`.
- ⚠️ **`_selectionAllowed` инициализируется в `true`, а не в `false`** — `GameBootstrapper.Awake()` входит в стейт-машину раньше, чем Zenject-кернел вызовет `Initialize()`, то есть первый `PreBattlePhaseStartedSignal` сервис не услышит. Рестарт работает: `PreBattleState.Enter()` фаерит Started при каждом входе, включая внутрипроцессный.
- **`AnimalMover` — чистый переводчик жеста в намерение**, знания про UI нет. Тап выбирает · повторный тап по тому же снимает · тап по пустому снимает · драг сбрасывает и карточку не показывает · **выбор переживает отпускание пальца**. `Clear()` только на промахе рейкаста и в `BeginDrag` (не на каждом нажатии — иначе мигание карточки и провал подсветки на ~150 мс при переключении между животными). `TryPickAnimal()` обнуляет `_current` первым действием.
- **Карточка** — `AnimalStatsPanelView` + `AnimalStatsPanelPresenter` + `Assets/Prefabs/AnimalStatsPanelView.prefab`, биндинг в `BattleInstaller` (`FromComponentInNewPrefab` + презентер `NonLazy`). Screen-space-overlay, следует за животным (`WorldToScreenPoint` → `ScreenPointToLocalPointInRectangle`, как `DamagePopupController`/`MergePopupController`/`TutorialHandView`). `ResolvePanelPosition` + `CoversAnchor` переключают сторону по **склампленному** результату — на сыром офсете в полосе x ∈ [−393, −123] карточка накрывала описываемое животное.
- **Презентер читает `AnimalFacade.GetDamage()` / `GetCurrentHealth()`, НЕ `AnimalStats`** — мердж мутирует рантайм-значения (`MergeTarget.ExecuteMergeDirectly`). Живое обновление по `Health.HealthChanged`. Зависимости от `SignalBus` у презентера нет — гейт фазы в сервисе.
