## Фича: эффект «loot shine» — переливающаяся волна света по объекту

### Done
- Новый шейдер `Assets/Shaders/IridescentSweep.shader` (`Voodoo_LaunchOps/FX/IridescentSweep`) — Built-in RP, ShaderLab + CG, unlit **аддитивный оверлей** вторым слотом материала: базовый lit-материал не трогается вообще. `Blend One One`, `ZWrite Off`, `ZTest LEqual`, `Offset -1,-1`, `Fallback Off`, `ForceNoShadowCasting`, `Queue Transparent+1`, `DisableBatching True`, `#pragma target 3.0`, один безусловный вариант. 18 свойств, без комментариев (правило проекта).
- Анимация целиком на `_Time.y` — **C#-контроллера нет, Zenject-биндинга нет, сигнала нет, DI-поверхность нулевая.**
- Волна: `phase = sweepCoord * _SweepTiling - _Time.y * _SweepSpeed + _PhaseOffset`, полоса через `1 - smoothstep(0, _SweepWidth, abs(frac(phase) - 0.5) * 2)` (симметрична относительно wrap-а `frac` → шов бесшовен по построению). Fresnel-терм `pow(1 - saturate(dot(normal, viewDir)), _RimPower)` даёт свечение по всему силуэту/периметру. Переливы — один `cos` между двумя HDR-цветами, оттенок сдвигается тем же Fresnel-термом (эффект масляной плёнки от угла обзора).
- Новый материал `Assets/Code/Animals/Materials/IridescentSweepOverlay.mat` — рядом с владеющим модулем, по прецеденту `Assets/Code/GridPathfinding/Materials/`.
- `Assets/Resources/Prefabs/Animals/Cheetah.prefab`: ровно 2 override-записи на вложенном инстансе `Fox tail Variant` — у `SkinnedMeshRenderer` `Fox Tail` (`CG/Pelvis/Tail/Fox tail Variant/Fox Tail`) массив материалов 1 → 2, элемент 0 не тронут (`Fox Skin Mane Wolf`), элемент 1 = оверлей. `m_IsActive` намеренно оставлен `0`.
- `Assets/Animals compilation/Prefabs/Fox tail Variant.prefab` НЕ редактировался — он общий для 10 префабов (Cheetah, Deer, EnemyCheetah_Temp, Elephant, Archive/Elephant, Porcupine Variant, Leopard Variant, Chicken, Elk, Elephant_PA Grey).

### Decisions
- **Аддитивный оверлей вторым слотом, а не форк Standard.** Форк дал бы 1 draw call вместо 2, но требует переписать все свойства Standard и меняет базовый вид. Оверлей выводит только свечение (чёрный = невидим) → ни сортировки альфы, ни воспроизведения освещения Standard. Подробности → [[2026-07-31-iridescent-sweep-shader]].
- **`_SweepTiling` = «полос на объект», а не «полос на мировую единицу»** — критичная находка ревью. Первая версия мерила сырые object-space единицы: при `_SweepTiling = 0.4` на хвосте с Y-размахом 0.5502 полоса выходила шире объекта → вместо волны равномерное мигание ~1.67 с. Добавлен `_SweepAxisExtent`, координата делится на него.
- **Мягкий rolloff `glow / (1 + glow)`** до умножения на тинт: проект в Gamma, пост-обработки в `Main Scene.unity` нет, значения > 1 просто клампятся. Без rolloff рим выбивал каналы в белый (`glow ≈ 2.03`) ровно там, где эффект сильнее всего, убивая переливы.
- **Без GPU instancing** — Unity не поддерживает instancing для `SkinnedMeshRenderer`; `_PhaseOffset` оставлен обычной uniform (по-прежнему выставляется через `MaterialPropertyBlock`).
- **Совместимость с мерджем проверена, а не предположена**: `CheetahMergeAttribute.cs:32,46` — единственная запись материала животного во всём `Assets/Code`, массивные формы (`.materials`/`.sharedMaterials`) не присваиваются нигде; одиночный `Renderer.material` меняет элемент 0 и сохраняет длину массива.
- **Контроллер отложен осознанно.** Если шиммер позже должен срабатывать по событию (мердж / выбор / награда) — `Assets/Code/Animals/Visuals/SweepGlowView.cs`, Presentation, тупая view по образцу `MergePopupView`/`UiPulseAnimator`, `MaterialPropertyBlock` + `SetPropertyBlock(block, materialIndex)` (форма — `Code/GridPathfinding/GridCell.cs:136-143`), UniTask + DOTween, без биндинга.

### Decisions
- **Дух = запечённая копия меша самой курицы, а не отдельный арт.** Ноль новых ассетов, силуэт узнаётся как «душа именно курицы», механизм бесплатно переносится на других животных. Подробности → [[2026-07-31-chicken-death-spirit]].
- **`Any State` вместо перехода из конкретного стейта** — исходная разводка ловила смерть только из `idle`, это и была причина «анимации смерти нет» в большинстве случаев.
- **`IsDead` сделан Bool + `canTransitionToSelf = false`.** Связка обязательная: Bool остаётся `true` вечно, и при `canTransitionToSelf = true` переход перезапускался бы каждый кадр, заморозив анимацию на первом кадре.
- **Переход смерти поставлен индексом 0**, раньше существовавшего `Any State --TakeDamage--> damage`: `AnimalHealth.TakeDamageAsync:142-147` зовёт `TakeDamageAnimation()` прямо перед `Die()`, оба конкурируют в одном кадре, порядок в `anyStateTransitions` = приоритет.
- **Дух спавнится без родителя** — тело уничтожается через 3 с (`DestroyWithDelay`), ребёнок умер бы на середине полёта.
- **Затухание через множитель на весах свечения, а не через альфу** — шейдер аддитивный, альфа в нём не участвует.
- **Пул не делался**, хотя `UnityPatterns.md` требует пул для VFX: смертей единицы за бой, а запечённый меш уникален на каждый вызов — переиспользовать почти нечего. Прецедент — `DamagePopupView`.
