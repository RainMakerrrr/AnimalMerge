### Decisions
- **Команды идут внутрь через интерфейсы, факты — наружу через `SignalBus`.** View тупые (`event Clicked`, `Set*(...)`), единственный клей — `PreBattleHudPresenter : IInitializable, IDisposable`. Подробности → [[2026-07-31-pre-battle-phase-architecture]].
- **Новое условие старта боя = один класс `IBattleReadinessRule` + одна строка биндинга.** `BattleReadinessService` агрегирует `IBattleReadinessRule[]` по И.
- **`MinAllyCountRule` считает по high-water mark, а не по текущему счётчику** — наивное `>= 2` создавало софт-лок при мердже двух союзников в одного. Подробности → [[2026-07-31-min-ally-count-high-water-mark]].
- **Стартовый пул вынесен в данные (`PreBattleConfig`)**, дублирование с пулом подкреплений `AnimalSpawner._animalTypes` оставлено намеренно — объединение вне скоупа.
- **Сцена намеренно не редактировалась**: Unity Editor общий для параллельных сессий, в рабочем дереве висел неподтверждённый чужой дифф `Main Scene.unity`. Обвязка отдана пользователю списком шагов (см. Next).
