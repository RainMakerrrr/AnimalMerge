### Новый opt-in контракт описания способности

- `Code/Abilities/AbilityKind.cs` (enum `Dodge` / `CounterAttack` / `Retreat`).
- `Code/Abilities/AbilityDescription.cs` — readonly struct `Kind` + `ChancePercent`.
- `Code/Abilities/IDescribableAbility.cs` — метод `Describe()`.
- Намеренно **не** добавлено в `IAbility` — иначе ломается компиляция тестовой сборки (рукописные

- `Dodge`, `CounterAttack`, `RetreatAbility` реализуют интерфейс и отдают свой приватный
  `_successChance`.

### Провайдер строк карточки

- `Code/Animals/UI/AbilityLinesProvider.cs` / `IAbilityLinesProvider.cs`: идёт по
  `AnimalFacade.AbilityManager.Abilities` в порядке регистрации, группирует по `AbilityKind` с
  сохранением порядка первого появления, внутри группы берёт **максимальный** шанс (лиса, влитая в
  лису, несёт два `Dodge` — owner 50 + inherited 30 — итог одна строка «50% Dodge»).
- Гардит `animal == null` и `AbilityManager == null` (фасад создаёт менеджер в `Start()`).
- Формат строки: шанс ≤ 0 или ≥ 100 → только имя способности, иначе `"{chance}% {name}"`.
- Способность без `IDescribableAbility` — `Debug.LogWarning`, а не тихое выпадение из карточки.

## Decisions

- **Opt-in `IDescribableAbility`, а не расширение `IAbility`.** Минимальный blast radius: не
  трогает тестовые моки под TESTS PAUSED, новая способность без реализации не ломает сборку — лишь
  не попадает в карточку (с явным `Debug.LogWarning`).
- **Дубли одной способности схлопываются по максимальному шансу.** Сознательная неточность: два
  независимых броска 50%+30% дают ~65% совокупно, карточка показывает номинал 50%, а не эффективную
  вероятность. Расчёт эффективного шанса в UI-слое сочтён избыточным ради одной строки текста.
- **Названия на английском** (`Dodge` / `Counter` / `Retreat`) — консистентно с остальным HUD
  (LEVEL / FIGHT / ADD ANIMAL / UNDO MERGE).
- **Способность со 100% шансом рендерится без процента** — владелец-велоцираптор показывает просто
  «Retreat».
- Подробности и рассмотренные альтернативы — [[2026-09-12-animal-card-ability-lines]].
